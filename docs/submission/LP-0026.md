# Solution for LP-0026 — Agora

Submitted by: @stevancarlon

**Prepared submission materials.** Verification limits are stated below; this document does not claim every prize criterion has been met.

## Summary

Agora is a native, local-first forum for Logos Basecamp. C++17 and Qt/QML provide a compact discussion interface; SQLite keeps identities, drafts and posts on the user's device. Logos Delivery exchanges signed posts and retrieves missed history. Logos Storage exchanges content-addressed attachments.

## Approach

Native Qt integrates with Basecamp's module API and avoids a separate browser-hosted application server. SQLite makes failed sends and drafts durable. Backend validation, signing, persistence and media handling are separate from QML presentation. The early React prototype is historical; it is not the shipped app. Delivery and Storage provide peer transport and content addressing without a centralized application backend. Public discussion posts are not end-to-end encrypted; anonymous display does not promise network anonymity.

## Success criteria

- [x] Native Basecamp UI and local build instructions. Current 0.3.4 Linux kit; four desktop variants available in the earlier 0.3.2 release.
- [x] Multiple identities, alias/UID/anonymous display and identity rotation.
- [x] Boards, threads, replies, quotes and local search.
- [x] Durable failed sends, retry and paged missed-message recovery implemented and tested on an isolated real relay/Store network.
- [x] Bounded send pacing, retry backoff and history pages.
- [x] Public Delivery acknowledgement and independent profile receipt, verified on one Linux host.
- [ ] End-to-end operation on Logos testnet **0.4**. Current public evidence identifies LEZ v0.3.1.
- [x] Native PNG/MP4/PDF upload and exact-byte retrieval through public discovery/relays between fresh readers on one computer.
- [x] Independent cross-machine public attachment retrieval. A fresh GitHub-hosted reader fetched PNG, MP4 and PDF from the persistent public provider with matching sizes and SHA-256 hashes.
- [ ] Realistic topics and organic community conversations. No authentic adoption claimed.
- [x] Narrated presentation of the actual forum, identities, quotes, multi-attachment layout and delivery icons. Eight sample posts have matching transport acknowledgements; network verification limits are stated.
